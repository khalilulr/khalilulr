### 🚀 Featured Project — [RentKarRideKar](https://github.com/khalilulr/RentKarRideKar) · Multi-Vehicle & Advance Ride Booking Platform

A microservices-based vehicle rental and ride-hailing platform that solves a gap on-demand apps ignore: **advance, multi-vehicle bookings** (e.g., 3 cars and a bus for one event) as a **single order** with one OTP, one payment, and one settlement.

- **9 microservices** (API Gateway, Auth, Booking, Search, Verification, Communication, Rating, Discount, Payment) built with **NestJS & TypeScript**
- Internal communication over **gRPC** with versioned `.proto` contracts and generated types, fronted by a centralized **REST API Gateway**
- **Database-per-service** architecture on **PostgreSQL** and **Redis** for fault isolation and scalability
- **JWT RS256** auth with refresh-token rotation & Redis blacklisting, plus a booking **state machine** with dynamic pricing and dispute resolution
- Real-time tracking and chat via **Socket.IO**, a **KYC** verification pipeline, and **Docker Compose** orchestration validated by **Jest** E2E tests
